## App infrastructure and Electron

- `app/layout.tsx`: document, fonts, skip link, global providers. Shown across pages.
- `app/providers.tsx`: query cache and runtime provider; no independent visual component.
- `(nav_pages)/layout.tsx`: sidebar, search, creation/detail hosts, notifications and page container.
- `docs/layout.tsx`, `sheets/layout.tsx`: persistent list panes and content split.
- `proxy.ts`: login/onboarding access gates and legacy `/m` redirect; no standalone screen.
- `electron/main.ts`: application window, File/Edit/View/Window menus, external-link handling, single-instance lifecycle and startup error dialog. Actual Linux renderer captured; platform menus, startup failure, macOS and Windows were reviewed in source only.
- `electron/preload.ts`: platform/version bridge, no independent screen.
- Stores, hooks, API clients, types, formatting/formula/scheduling utilities and global CSS support these surfaces; they are not independent screenshot targets.
