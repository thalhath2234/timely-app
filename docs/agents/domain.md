# Domain docs

This repo uses one domain context.

Before exploring a domain area, read the root `CONTEXT.md` and relevant
ADRs in `docs/adr/`. Also check app-level ADRs when working in that app.

Use the terms defined in `CONTEXT.md`; avoid synonyms the glossary
rejects. If a needed concept is missing, note it for domain modeling.
Surface any conflict with an accepted ADR explicitly.

If a referenced domain file is absent, continue without treating its
absence as an error.
