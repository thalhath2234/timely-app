- Cloud env "timely" (OpenRouter key rejected as of 2026-10-15; no model key, so agent-chat flows are tested by calling the MCP tools or API directly). No emulator: phone tested as Expo web at 390px (CORS_ORIGINS=http://localhost:8082, EXPO_PUBLIC_API_URL=http://localhost:8081); the phone doc editor does not load in that preview (harness: [phone-doc-editor-web-harness](phone-doc-editor-web-harness.md)). Yoga-only layout bugs (Android flex/Text stretch) don't show on Expo web; board-card thread simulated Yoga to prove one (2026-10-20). `next dev` on 4002 can pick up a `git stash pop` mid-run (2026-10-31): restart web after every code switch and check the before shot shows the bug.  Cloud APK build works [cloud-apk-build](cloud-apk-build.md). 
- PSTACK SKILLS in repo (#235, merged into dev 2026-10-19, thread's report): pstack from Cursor marketplace (github.com/cursor/plugins) copied into timely-app with `make pstack-sync` (update command); CLAUDE.md points threads at it. New threads can run /poteto-mode (router), /why, /how, /arena, /interrogate and the other ~56 skills; 2 helper agents. User's PC also has the plugin installed locally.
- User sometimes says "use fable" (switch thread to Claude Fable 5.1). Project channel model was Fable from 2026-10-18; user switched the channel session to Opus 5.5 (1M) on 2026-10-19 12:18 and cleared the default thread model (effort xhigh).
- DOCKER WORKS in the cloud container (2026-10-23, API URL thread): start `dockerd` in the background. Docker Hub gives 429; pull `mirror.gcr.io/library/node:22-alpine` and tag it. Builds need the proxy CA: a scratch copy of the Dockerfile that COPYs /root/.ccr/ca-bundle.crt (via --build-context), appends it to /etc/ssl/certs/ca-certificates.crt (Turbopack fetches Google Fonts natively) and sets NODE_EXTRA_CA_CERTS. Real API + Postgres 16 also run: initdb under /var/tmp (postgres user cannot reach the scratchpad), DB_PASSWORD must be non-empty, API_BIND=127.0.0.1,172.17.0.1 so containers reach it.
- AGENT CHAT END TO END WITHOUT A MODEL KEY (2026-10-26, OpenUI thread): run a tiny stand-in Ollama server (native /api/tags, /api/show, /api/chat) on 127.0.0.1, then POST /agent/providers/ollama/key {baseUrl} and PATCH /agent/providers {defaultProvider:"ollama", models:{ollama:"<name>"}} for the test account. The real runner then calls it with tools; the stand-in can call list_tasks and answer from the tool result. Test tokens last 30 min: log in again before API checks.
- NO PUBLIC LINK FROM THE CLOUD (2026-10-27): safety checks refuse tunnels even with the user's OK. Walkthrough videos instead: [cloud-walkthrough-videos](cloud-walkthrough-videos.md).
- E2E GOTCHAS (2026-10-26, live blocks): the account's saved appearance (PUT /config {appearance:{theme}}) beats the browser's colorScheme on web AND phone, so set it at the start of every themed run. MCP parity (`make` parity script) registers accounts: start the API with ALLOW_REGISTRATION=true. On Expo web, the doc title input widens the page past 390px: inject `input{min-width:0}`. The BackHandler dev toast sits in a shadow root: hide its host. A stale Expo on 8082 makes a new start skip: kill the port holder first.
- PNPM IN A WORKTREE BREAKS THE MAIN CHECKOUT (2026-10-31): `pnpm install` in a git worktree under the scratchpad relinked the main checkout's apps/*/node_modules and packages/*/node_modules into the worktree (Turbopack then failed "symlink points out of the filesystem root"). Fix: rm those node_modules dirs and `pnpm install --frozen-lockfile --prefer-offline` in the main checkout. For "before" shots, `git stash` in the main checkout instead. Jev stand-in and its gotchas: [jev-stand-in-testing](jev-stand-in-testing.md).
- E2E (2026-10-31): /login is rate limited (log in once per run, cache tokens); new accounts hit /onboarding until configs.is_on_boarding_completed=true.
- EXPO WEB DRAWS RAW TEXT THAT PHONES DO NOT (2026-11-03, model names thread): strings handed to a View show on Expo web but vanish on Android. To prove such a bug at 390px, run a "phone rule" in Playwright that blanks text nodes whose parent has class css-view-* (script /mnt/project-files/phone-model-names/shoot.cjs; [phone-model-names](phone-model-names.md)); the count of blanked nodes is the before/after number.
