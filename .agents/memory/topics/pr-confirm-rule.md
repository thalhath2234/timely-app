In the grouped task forms thread the user said "Dont open pr until i confirm" while work was in progress.

**Why:** They want to review the result (screenshots, branch) before a PR exists.
**How to apply:** Applies to that thread for sure; in other threads, if the user has asked this, push the branch, share screenshots, and ask before opening the PR. Don't assume it for every thread unless they repeat it. Related: [grouped-task-forms](grouped-task-forms.md).
