When making any UI change in Timely, always use the design skills (design:design-critique, design:design-system, and the others) before building, even for small follow-ups like filling empty space on a page. Write the critique to the project folder next to the screenshots.

**Why:** On 2026-10-11 the user said "when doing ui changes always use design skill". They had asked to fill the empty right side of the new Inbox, and earlier they rejected a landing page as "too generic".
**How to apply:** Critique the current screen with design:design-critique, then build from the shared kit [design-system](design-system.md), then take screenshots.
